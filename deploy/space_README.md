# Repo Brain

A company brain for open-source orgs, built on FalkorDB for Graph Hacks (WeMakeDevs x FalkorDB).
This Space holds a year of the public FalkorDB org's GitHub activity (about 40k nodes) in a
FalkorDB graph running inside the container. Ask who knows a piece of code, why something was
decided, or what a change will drag along: every answer is cited and its graph path is drawn.

Source, graph model and Cypher queries: https://github.com/elgombe/graph-hacks

MCP endpoint (streamable HTTP): `https://<this-space>.hf.space/mcp/`
